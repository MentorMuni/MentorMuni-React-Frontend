INTERACTION STATE MACHINE
═══════════════════════════════════════════════════════════════════════════

IDLE → FOCUS → VALIDATION → SUBMIT → LOADING → SUCCESS/ERROR

Email Focus State:
  - Icon turns cyan
  - Border glows
  - Underline grows left-to-right (300ms spring)
  - Box shadow expands
  - Ready for input

Validation Flow:
  1. User types in field
  2. User blurs field (tabs away)
  3. Validation check runs
  4. If valid: Green checkmark appears (300ms bounce)
  5. If invalid: Field shakes 4x, red border, error message

Loading State:
  - Spinner rotates infinitely (2s linear)
  - Button disabled (pointer-events: none)
  - Background pulsing glow (1.5s ease-in-out)
  - No user interaction possible

Success State:
  - Form fades out (300ms)
  - Success checkmark bounces in (500ms spring)
  - Success message displays
  - Auto-redirect after 1200ms

Error State:
  - API error toast appears at top
  - Shake animation (±10px x4)
  - Red border + icon highlight
  - User can retry

VALIDATION LOGIC
═══════════════════════════════════════════════════════════════════════════

Email Validation:
  ├─ Required: email !== ''
  ├─ Format: matches /^[^\s@]+@[^\s@]+\.[^\s@]+$/
  └─ Real-time: on blur, show instant feedback

Password Validation:
  ├─ Required: password !== ''
  ├─ Minimum: length >= 6 characters
  └─ Real-time: on blur, show instant feedback

Form Submit:
  ├─ Validate all fields
  ├─ Show loading state
  ├─ Call API: loginStudent(email, password)
  └─ Handle response (success/error)

STATE MANAGEMENT
═══════════════════════════════════════════════════════════════════════════

Form Data:
  - email: string (user input)
  - password: string (user input)
  - rememberMe: boolean

UI State:
  - loading: boolean (API in progress)
  - success: boolean (login succeeded)
  - errors: object (field-level errors)
  - touched: object (field visited)
  - apiError: string (server error)
  - successMessage: string (welcome text)

Event Handlers:
  - handleEmailChange() → real-time validation
  - handlePasswordChange() → real-time validation
  - handleEmailBlur() → validate on blur
  - handlePasswordBlur() → validate on blur
  - handleSubmit() → API call
